# Самопроверка оформления ВКР

Страница, где студент загружает .docx **без титульного листа** и получает отчёт: что исправить, где (страница или раздел, фрагмент текста) и по какому пункту ГОСТ 7.32-2017, методички или ГОСТ Р 7.0.100-2018.

Проверка выполняется в браузере студента (Pyodide + lxml в Web Worker). Файл никуда не отправляется.

## Устройство

| Путь | Что это |
|---|---|
| `web/index.html`, `app.js`, `style.css` | страница и отчёт |
| `web/worker.js` | загружает Pyodide, запускает проверку |
| `web/py/normokontrol_core.py` | слой A: вёрстка, заголовки, таблицы, содержание, перечисления |
| `web/py/normokontrol_biblio.py` | список источников и ссылки на него |
| `web/py/normokontrol_service.py` | сборка отчёта |
| `web/rules.json` | уровни («Исправьте»/«Проверьте»), источники требований, тексты «что сделать» |
| `web/pyodide/` | Pyodide 314.0.7 и lxml 6.1.3 из официального релиза (sha256 lxml — в `pyodide-lock.json`) |
| `tests/` | тесты модуля списка литературы |
| `legacy/` | исходный код слоя A (v0.8) |

## Уровни замечаний

«Исправьте» — правила с точностью не ниже 64 % на размеченном корпусе (реестр v0.8) и детерминированные проверки списка источников (число источников, ссылка на несуществующий номер). Остальные — «Проверьте». Изменить уровень можно в `web/rules.json`.

## Запуск локально

```
cd web && python3 -m http.server 8000
```
Открыть http://localhost:8000. Тесты: `pip install lxml && python tests/test_biblio.py`.
