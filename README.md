# Самопроверка оформления ВКР

Страница, где студент загружает .docx **без титульного листа** и получает отчёт: что исправить, где (страница или раздел, фрагмент текста) и по какому пункту ГОСТ 7.32-2017, методички или ГОСТ Р 7.0.100-2018. По каждому замечанию студент фиксирует решение («исправил» или «оставляю» с пунктом ГОСТ и причиной) и скачивает лист самопроверки в формате .docx.

Проверка и сборка листа выполняются в браузере студента (Pyodide + lxml в Web Worker). Файл и решения никуда не отправляются.

## Устройство

| Путь | Что это |
|---|---|
| `web/index.html`, `app.js`, `style.css` | страница и отчёт |
| `web/worker.js` | загружает Pyodide, запускает проверку |
| `web/py/normokontrol_core.py` | слой A: вёрстка, заголовки, таблицы, содержание, перечисления |
| `web/py/normokontrol_biblio.py` | список источников и ссылки на него |
| `web/py/normokontrol_service.py` | сборка отчёта (все замечания с идентификаторами) |
| `web/py/normokontrol_sheet.py` | проверка решений и сборка листа самопроверки (.docx без сторонних библиотек) |
| `web/rules.json` | уровни («Исправьте»/«Проверьте»), источники требований, тексты «что сделать» |
| `web/pyodide/` | Pyodide 314.0.7 и lxml 6.1.3 из официального релиза (sha256 lxml — в `pyodide-lock.json`) |
| `tests/` | тесты списка литературы и листа; `corpus_regression.py` — регрессия на корпусе (работы в репозиторий не кладутся) |
| `legacy/` | исходный код слоя A (v0.8) |

## Лист самопроверки

Решения: по замечанию уровня «Проверьте» — «исправил» или «оставляю»; для «оставляю» обязательны пункт ГОСТ или методички (с цифрой) и причина (не короче 15 знаков). Для «Исправьте» достаточно «исправил»; если замечание ложное, есть «не согласен(на), оставляю» с теми же полями. Лист формируется, когда решение принято по каждому замечанию. В листе сначала «Оставлено без изменений», затем «Исправлено». В лист не попадают имя файла, титульный лист и ФИО; метаданные автора пустые; во фрагментах маскируются e-mail и телефоны; есть переключатель «не включать фрагменты». Решения не сохраняются при закрытии страницы.

## Уровни замечаний

«Исправьте» — правила с точностью не ниже 64 % на размеченном корпусе (реестр v0.8) и детерминированные проверки списка источников (число источников, ссылка на несуществующий номер). Остальные — «Проверьте». Изменить уровень можно в `web/rules.json`.

## Запуск локально

```
cd web && python3 -m http.server 8000
```
Открыть http://localhost:8000. Тесты: `pip install lxml && python tests/test_biblio.py && python tests/test_sheet.py`. Регрессия на корпусе: `python tests/corpus_regression.py <папка_с_docx>`.
